# Установка WB MCP Server на новом Mac (инструкция для Claude)

Ты находишься на новом Mac mini. Этот архив — полный перенос WB MCP Server v2.0.
Выполни шаги по порядку.

## Состав архива

```
wb-mcp-server/        # исходники (git-репозиторий)
wb_data_backup.tar.gz # данные: магазины с токенами (зашифрованы) + ключ + статистика
УСТАНОВКА.md          # этот файл
```

## Шаг 1. Проверить Docker

```bash
docker info > /dev/null && echo OK
```

Если Docker не установлен — установить Docker Desktop или OrbStack, затем включить
автозапуск при входе (Docker Desktop → Settings → General → Start when you sign in).

## Шаг 2. Разместить проект

```bash
mkdir -p ~/Documents/myProjects
mv wb-mcp-server ~/Documents/myProjects/
cd ~/Documents/myProjects/wb-mcp-server
```

## Шаг 3. Настроить окружение

```bash
cp .env.example .env
# Сгенерировать токен авторизации MCP и вписать в .env → MCP_AUTH_TOKEN=
openssl rand -hex 32
```

Отредактируй `.env`: вставь сгенерированное значение в `MCP_AUTH_TOKEN`.
Покажи токен пользователю — он понадобится для подключения OpenClaw.

## Шаг 4. Собрать и запустить

```bash
docker compose up -d --build
sleep 8
curl -s http://localhost:8001/api/health
```

Ожидаемый ответ: `{"status": "ok", "auth_enabled": true, ...}`.

## Шаг 5. Восстановить данные магазинов (токены WB)

`wb_data_backup.tar.gz` лежит рядом с папкой проекта (в корне распакованного архива).

```bash
docker compose down
docker run --rm -v wb-mcp-server_wb_data:/data -v "$(dirname "$(pwd)")":/backup alpine \
  sh -c "cd /data && tar -xzf /backup/wb_data_backup.tar.gz"
docker compose up -d
```

Если бэкапа нет — пропусти шаг: магазины можно добавить вручную через
http://localhost:8001/shops (нужны WB API токены).

## Шаг 6. Проверить работоспособность

```bash
# Магазины восстановились (ожидается: ИП 4055573, Novel 3937117)
curl -s http://localhost:8001/api/health
# Полная диагностика: ping всех хостов WB + пробы категорий + срок токенов
curl -s -X POST http://localhost:8001/api/diagnostics/run --max-time 150
```

Ожидается `"healthy": true` по каждому магазину. Детали: http://localhost:8001/diagnostics

⚠️ Если диагностика показывает 429 — это лимиты WB (не ошибка), повтори через минуту.

## Шаг 7. Подключить OpenClaw

В конфигурации MCP-серверов OpenClaw добавь (подставь IP/имя этого Mac и токен из шага 3):

```json
{
  "mcpServers": {
    "wildberries": {
      "type": "sse",
      "url": "http://<IP-этого-мака>:8001/sse",
      "headers": { "Authorization": "Bearer <MCP_AUTH_TOKEN>" }
    }
  }
}
```

Если клиент не умеет заголовки: `http://<IP>:8001/sse?token=<MCP_AUTH_TOKEN>`.

Узнать IP этого мака: `ipconfig getifaddr en0` (или использовать `<имя-мака>.local`).

## Шаг 8. Финальная проверка с машины OpenClaw

```bash
curl -s -H "Authorization: Bearer <MCP_AUTH_TOKEN>" "http://<IP>:8001/sse" --max-time 3 | head -2
```

Ожидается событие `event: endpoint`. Без токена должно возвращать 401.

## Безопасность

- НЕ пробрасывать порт 8001 в интернет. Для доступа извне локальной сети — Tailscale.
- После успешной установки удалить `wb_data_backup.tar.gz` и сам архив переноса
  (содержат ключ шифрования и токены WB): подтверди у пользователя и удали.
- Веб-дашборд (/, /shops, /diagnostics) доступен без авторизации всем в локальной сети.
