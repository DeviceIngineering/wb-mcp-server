# Cursor

**SSE поддерживается нативно.** Мост не нужен.

## Способ 1: через интерфейс

Панель **Customize** в боковой панели → раздел MCP → добавить сервер и включить его
тумблером. Отдельной консольной команды для добавления MCP-сервера в документации
Cursor нет — **не подтверждено**.

## Способ 2: правка файла конфигурации

| Область | Путь |
|---|---|
| Глобально | `~/.cursor/mcp.json` |
| Для проекта | `.cursor/mcp.json` в корне проекта |

На Windows это `%USERPROFILE%\.cursor\mcp.json` — в документации Cursor отдельный
Windows-путь не приведён, **не подтверждено**, но каталог тот же `~/.cursor`.

Через интерфейс: панель **Customize** в боковой панели → раздел MCP → добавление
и включение серверов. Оттуда же открывается `mcp.json`.

## Конфигурация

Для удалённого сервера Cursor использует поле `url`; поле `type` документировано
как обязательное только для stdio-серверов.

Без авторизации:

```json
{
  "mcpServers": {
    "wildberries": {
      "url": "http://localhost:8001/sse"
    }
  }
}
```

С `MCP_AUTH_TOKEN` — Cursor раскрывает `${env:ИМЯ}` в полях `url` и `headers`:

```json
{
  "mcpServers": {
    "wildberries": {
      "url": "http://localhost:8001/sse",
      "headers": {
        "Authorization": "Bearer ${env:WB_MCP_TOKEN}"
      }
    }
  }
}
```

Переменную `WB_MCP_TOKEN` нужно задать в окружении оболочки, из которой запускается
Cursor. Для удалённых серверов `envFile` **не поддерживается** — только окружение.

Если клиент запускается так, что переменную не подхватить, токен можно передать
прямо в URL — сервер принимает `?token=`:

```json
{
  "mcpServers": {
    "wildberries": {
      "url": "http://localhost:8001/sse?token=ВАШ_MCP_AUTH_TOKEN"
    }
  }
}
```

Так токен попадает в файл конфигурации и в логи открытым текстом — используйте
только в доверенной среде.

## Проверка

- Панель **Customize** → у сервера виден статус и раздел **Available Tools**
  (должны появиться инструменты `wb_*`).
- Логи: `Cmd+Shift+U` → вкладка **MCP Logs**.
- Спросите ассистента: «покажи список моих магазинов на Wildberries».

## Оговорки

- Вариант `"type": "sse"` встречается на форуме сообщества, но в официальной
  документации Cursor не описан — **не подтверждено**. Работающая по документации
  форма — просто `url`.
- Явного разрешения или запрета на `http://` (без TLS) в документации нет.
- В корпоративных настройках может действовать MCP Allowlist, разрешающий удалённые
  серверы только по заданным URL-шаблонам.
