# Справочник инструментов

Всего инструментов: **202**.

Список сгенерирован из `wb_mcp/server.py` (список `TOOLS`) — он же отдаётся клиенту
в ответ на `tools/list`. Метки `[P0]`…`[P3]` — приоритет инструмента для бизнеса:
P0 — прямые денежные потери, P1 — операционные метрики, P2 — справочники,
P3 — администрирование.

Каждый инструмент, кроме `wb_list_shops` и `wb_degradations`, принимает обязательный
параметр `shop_id` (см. `wb_list_shops`). Если магазин в системе один, `shop_id`
можно не передавать — сервер подставит единственный доступный.


## Магазины

1. **`wb_list_shops`** — Список зарегистрированных магазинов Wildberries. Возвращает shop_id и название. Используй shop_id для всех остальных инструментов.

32. **`wb_promotions_auto`** — [P0] ТОЛЬКО автоакции (type=auto) за период — WB добавляет товары автоматически. Используй для регулярного мониторинга, чтобы цены не упали без твоего ведома.  
   Параметры: `start`*, `end`*
33. **`wb_promotions_audit`** — [P0] Аудит участия: в какие акции WB УЖЕ добавил мои товары и каков ценовой эффект (price→planPrice, % падения, скидка). ВАЖНО: для автоакций состав товаров WB через API не отдаёт (помечаются nomenclaturesAvailable=false) — контроль цен через wb_prices_list/wb_prices_quarantine. Авто-throttle под лимит 10 req/6 сек.  
   Параметры: `start`*, `end`*, `only_auto`, `max_promotions`
34. **`wb_promotions_details`** — [P1] Детали акций: даты, условия (ranging/boost), слоты участников, participationPercentage, бонусы (advantages), type.

35. **`wb_promotions_products`** — [P1] Товары, подходящие для акции. in_action: true = уже участвуют, false = не участвуют. Возвращает price/planPrice и discount/planDiscount.  
   Параметры: `promotion_id`*, `in_action`, `limit`, `offset`
36. **`wb_promotions_add_products`** — [P1] Добавить товары в акцию. upload_now=false — отложенно (применится при старте акции). Возвращает uploadID для отслеживания.  
   Параметры: `promotion_id`*, `nm_ids`*, `upload_now`
37. **`wb_promotion_exit`** — [P0] Выйти из акции/автоакции — восстановить цену и скидку (отдельного API выхода у WB нет, делается через Prices API).
